# Сеть GPS-башен

:::version В разработке
Этот раздел описывает локальное изменение после базовой ревизии исходников, указанной внизу страницы. Радиосеть и переключатель координат могут отсутствовать в опубликованной или установленной у вас сборке. Базовый API башни описан на [странице блока](/ru/block/gps_tower).
:::

Сеть состоит из явно подключённых башен. Одну из них назначают главной через программу на компьютере. Она становится нулём, а остальные сообщают смещение от неё. Башни другой сети не участвуют в передаче, даже если стоят рядом.

## Настройки

В `config/oc2r-common.toml` добавьте параметры в существующий раздел `[gameplay]`:

```toml
[gameplay]
relative_coordinates = true
gps_tower_range = 20
```

По умолчанию `relative_coordinates` выключен: башня возвращает свои обычные мировые XYZ. При включении она возвращает только смещение внутри своей сети. Если сигнала нет, выдаёт ошибку. Подмены результата мировыми XYZ не происходит.

Настройка действует на API GPS-башен. Координаты робота остаются локальными в обоих режимах. Формат сохранения Minecraft не меняется: служебные позиции по-прежнему хранятся на сервере и доступны владельцу файлов мира.

После изменения настроек перезапустите игру или сервер. Не смешивайте результаты, полученные в разных режимах координат.

## Назначить главную башню

Подключите одну собранную башню к компьютеру через интерфейсную шину. В Lua выполните:

```lua
local gps = assert(require("devices"):find("gps_tower"))
gps:setAsReference()
print(gps:getNetworkId())
```

Сохраните напечатанный ID сети. Это случайный идентификатор, не координаты.

Если в этой сети уже есть главная башня, назначение второй завершится ошибкой. Автоматического выбора по минимальному ID нет.

## Подключить следующую башню

На компьютере, подключённом к другой башне:

```lua
local gps = assert(require("devices"):find("gps_tower"))
gps:joinNetwork("вставьте-ID-сети")

if gps:hasSignal() then
    local p = gps:getPosition()
    print(p[1], p[2], p[3])
else
    print("Нет сигнала")
end
```

Для настройки подключайте по одной башне или выбирайте конкретное устройство через `devices:get(deviceId)`. При нескольких подходящих устройствах `find()` не выбирает ближайшее.

Принадлежность к сети не даёт сигнал на любом расстоянии. Нужна цепочка башен этой сети до главной. Если вы поставили башню далеко и не построили ретрансляторы, `getPosition()` не выдаст смещение.

## Дальность

По умолчанию между основаниями соседних башен должно быть не больше 20 блоков по прямой в трёх измерениях. Высота тоже учитывается. Например, смещение 20 по X и 1 по Y уже больше допустимой дальности.

Расстояние задаётся параметром `gps_tower_range`, от 1 до 1024 блоков. Цепочка может быть длиннее одного перехода. Стены и другие препятствия сигнал не ослабляют. Между измерениями связи нет.

## Выгруженные чанки

Состав сети сохраняется на сервере. Выгрузка чанка не удаляет башню из сети: она продолжает передавать сигнал по сохранённой схеме. Специально загружать чанк не требуется.

При разрушении любой части башни её узел удаляется. Если другого пути до главной нет, сигнал пропадает. При загрузке чанка сервер сверяет сохранённые узлы с реальными блоками.

Если сторонний редактор изменил выгруженный чанк, сеть узнает об этом после его загрузки. До проверки используется последнее известное состояние. Обычное разрушение блоков в игре обрабатывается сразу.

## Перенести начало координат

На прежней главной башне вызовите `clearReference()`. Затем на другой башне той же сети вызовите `setAsReference()`.

Это меняет всю систему отсчёта. Сохранённые точки и маршруты нужно обновить. После разрушения главной башни замена сама не выбирается: назначьте новую явно.

## Методы

| Метод | Результат |
|---|---|
| `getId()` | Постоянный ID башни |
| `getNetworkId()` | ID сети для подключения других башен |
| `getRange()` | Настроенная дальность одного перехода |
| `hasSignal()` | Есть ли путь до главной башни в относительном режиме |
| `isReference()` | Является ли целая башня главной |
| `setAsReference()` | Назначить главной, если в сети ещё нет другой |
| `clearReference()` | Снять роль главной |
| `joinNetwork(networkId)` | Подключить к существующей сети с главной башней |
| `getPosition()` | Массив `[x, y, z]`, в относительном режиме от главной башни |
| `getDimension()` | ID измерения |

В обычном режиме `hasSignal()` проверяет целостность башни, поскольку радиопуть для мировых XYZ не нужен. Команды изменения сети требуют `relative_coordinates = true`.

Сеть не отслеживает игрока и не добавляет роботу приёмник GPS. Планшет, позиционирование игрока и автоматическое получение роботом координат от башен требуют отдельной реализации.
