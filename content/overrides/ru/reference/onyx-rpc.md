# Устройства OnyxOS: oc2ctl

В комплектном образе OnyxOS есть `oc2ctl` и библиотека C для доступа к шине устройств OC2R. Они работают внутри гостевой ОС через `/dev/hvc0`. Ethernet для этого не нужен. Одновременно шиной RPC должен владеть только один процесс.

## Обнаружение и справка

Войдите как `root`. Если оболочка не находит команду по имени, используйте полный путь:

```text
run /bin/oc2ctl list
run /bin/oc2ctl methods robot
run /bin/oc2ctl call robot getEnergyStored
```

`list` показывает устройства; `methods TYPE` — реальные сигнатуры методов. Если устройств одного типа несколько, используйте `TYPE:UUID`, взяв UUID из списка.

## Робот и модули

| Команда | Условие и действие |
|---|---|
| `robot-status` | Состояние робота |
| `robot-demo` | Робот с питанием; свободная клетка впереди. Движение вперёд/назад, повороты вправо/влево |
| `inspect`, `scanner` | Нужен модуль сканера |
| `inventory` | Доступ к инвентарю |
| `inventory-demo` | Модуль операций с инвентарём, пустой выбранный слот и сундук с предметами прямо над роботом; взять один предмет и вернуть |
| `sound-demo` | Звуковая карта; запросить тон 880 Гц на 300 мс |

Например:

```text
run /bin/oc2ctl robot-status
run /bin/oc2ctl scanner
```

`robot-demo` проверяет завершение конкретного действия до `SUCCESS`. Принятие команды в очередь ещё не означает завершённое перемещение.

## Ошибки и ограничения

Общий вызов имеет вид `call TYPE METHOD JSON_ARRAY`. Учитывайте обработку кавычек оболочкой при передаче строк JSON.

Лимиты библиотеки: 8191 байт запроса, 32767 байт ответа, 32 уровня вложенности JSON, 5 секунд на RPC и 15 секунд на завершение действия. Подписки на события не предоставляются.

:::warn
После тайм-аута результат изменяющей команды неизвестен: устройство могло выполнить её без полученного ответа. Протокол не содержит идентификаторов запросов. Перед повтором сбросьте или перезагрузите шину виртуальной машины; простое переоткрытие `/dev/hvc0` не убирает запоздалые ответы.
:::

[Исходная техническая документация на английском](/en/reference/onyx-rpc) содержит устройство драйвера, сборку библиотеки и результаты проверок.
