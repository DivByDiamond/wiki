# Версии Minecraft и загрузчики

В текущих исходниках OC2R есть шесть целей сборки. Выбирайте файл под версию Minecraft и загрузчик своего экземпляра игры.

## Поддерживаемые цели

| Minecraft | NeoForge | Fabric | Java |
|---|---|---|---|
| 1.21.1 | Реализован | Реализован | 21 |
| 26.1.2 | Реализован | Реализован | 25 |
| 26.2 | Реализован | Реализован | 25 |

Порт Fabric для 26.1.2 и 26.2 принят, объединён с основной веткой и проверен в CI. Прежняя запись «Fabric 26.x в планах» устарела. Локальная проверка включала серверные тесты и запуск клиента на обеих современных версиях.

## Где брать файлы

Откройте [релизы OC2R](https://github.com/DivByDiamond/OC2R/releases) и проверьте имя артефакта. Наличие цели в исходниках не означает, что файл уже опубликован на каждой площадке. В указанной ревизии публикация новых целей Fabric 26.x оставлена отдельным шагом и отложена по решению владельца проекта.

Не переносите файл NeoForge в Fabric и наоборот. Зависимости тоже зависят от загрузчика и версии. Для Fabric используйте Fabric API, Team Reborn Energy и Forge Config API Port совместимых версий, указанных для выбранного файла.

## Как читать результаты проверок

Исторические разделы дорожной карты сохраняют состояние отдельных этапов. В начале текущего документа отмечено завершение всех шести целей. Для статуса реализации ориентируйтесь на эту запись и отчёт приёмки Fabric 26.x, а для доступности загрузки проверяйте конкретный релиз.

[Отчёт приёмки Fabric 26.x](https://github.com/DivByDiamond/OC2R/blob/39eb8109e2e38fdb047af98d8e6f7ded0194f498/docs/roadmap/fabric-26-acceptance.md) содержит матрицу и результаты проверок. Серверные настройки могут менять характеристики оборудования.
