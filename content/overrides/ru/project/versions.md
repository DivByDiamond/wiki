# Версии Minecraft и загрузчики

На этой странице перечислены цели сборки и проверки, записанные в ревизии исходников OC2R по ссылке ниже. Файл мода должен соответствовать и версии Minecraft, и загрузчику.

## Матрица сборок

| Minecraft | NeoForge | Fabric |
|---|---|---|
| 1.21.1 | Цель сборки и проверки | Цель сборки и проверки |
| 26.1.2 | Цель сборки и проверки | Будущая работа; узла сборки нет |
| 26.2 | Цель сборки и проверки | Будущая работа; узла сборки нет |

В исходниках предусмотрены четыре цели. В `settings.gradle.kts` включены три узла NeoForge и только узел Fabric 1.21.1. Сборки 26.x используют инструментарий Java 25, сборки 1.21.1 — Java 21.

## Доступность релизов

Процесс публикации настроен на эти четыре артефакта. Загрузка на отдельные платформы зависит от настроек репозитория и наличия собранного файла. Наличие цели сборки само по себе не означает, что конкретный релиз уже доступен на каждой площадке.

Перед установкой проверьте версию Minecraft и загрузчик в описании файла. Поместите JAR в каталог `mods` нужного экземпляра игры. Для Fabric также нужны объявленные зависимости: Fabric API, Team Reborn Energy и Forge Config API Port.

## Как читать планы разработки

Старый `docs/MULTILOADER.md` описывает первоначальный план на шесть сочетаний версий и загрузчиков. Для определения реализованных целей используйте текущую дорожную карту и конфигурацию сборки. Характеристики устройств могут зависеть от настроек сервера; содержимое вики относится к указанной ревизии исходников.
