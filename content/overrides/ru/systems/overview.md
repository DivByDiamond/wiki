# Операционные системы

Операционную систему выбирает прошивка компьютера. В OC2R доступны Linux (Minux / Buildroot) и OnyxOS. Перед заменой прошивки выключите компьютер.

## Linux

Linux подходит для первых экспериментов с Lua, библиотекой `devices` и встроенными примерами. Вход — `root`. [Первый запуск](/ru/getting_started) описывает установку компонентов.

Прошивка загружает ядро со встроенного корневого диска. Система сохраняет изменения в состоянии виртуальной машины. Отдельный жёсткий диск нужен для дополнительных данных, а не как обязательный загрузочный компонент.

Технические сведения о сборке образа, 9p и `/mnt/builtin` находятся в [документации Buildroot](/ru/systems/buildroot).

## OnyxOS

[OnyxOS](/ru/systems/onyxos) использует собственные ядро, файловую систему и пользовательские программы. Это другая гостевая среда: команды Linux и Lua-примеры нельзя автоматически считать совместимыми с ней.

Для работы с устройствами в комплектном образе есть [oc2ctl](/ru/reference/onyx-rpc). Проверенная конфигурация — четыре модуля памяти по 16 МиБ, всего 64 МиБ. Это проверенная конфигурация, а не установленный минимум для всех программ.

## Сохранения и смена прошивки

Linux и OnyxOS используют раздельные изменения корневых дисков. Дополнительные жёсткие диски остаются отдельными устройствами. Смена прошивки не переносит файлы между системами.

Обновление образа в моде также не устанавливает новые программы в уже сохранённый корневой диск. Для резервного копирования OnyxOS сохраняйте мир и каталог `config/oc2r/root-images/`; подробности и правила для старых миров приведены в [документации образов](/ru/systems/onyxos-reference).
