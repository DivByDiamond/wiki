# OnyxOS

OnyxOS — альтернативная гостевая ОС для компьютеров OC2R. Комплект включает прошивку OpenSBI, ядро OnyxKernel, оболочку и корневую файловую систему OnyxFS.

## Первый запуск

1. Выключите компьютер и установите прошивку OnyxOS.
2. Используйте четыре модуля памяти по 16 МиБ: 64 МиБ — конфигурация, на которой проверялся образ.
3. Подайте питание и включите компьютер.
4. Войдите как `root`, оставив пароль пустым.

Прошивка выбирает встроенный записываемый корневой диск OnyxFS на основе комплектного образа 16 МиБ. Отдельный жёсткий диск OnyxOS необязателен. Изменения сохраняются индивидуально для каждой виртуальной машины.

## Устройства Minecraft

Комплектная утилита `oc2ctl` использует `/dev/hvc0`, отдельный от сетевой карты и терминала канал. Начните с обнаружения устройств:

```text
run /bin/oc2ctl list
run /bin/oc2ctl methods robot
run /bin/oc2ctl robot-status
```

Дальнейшие примеры и требования к модулям — в [справочнике RPC](/ru/reference/onyx-rpc).

## Образы и существующие миры

Новые корневые диски запоминают SHA-256 базового образа. Исходный образ сохраняется в `config/oc2r/root-images/<sha256>.img`; этот каталог нужно включать в резервную копию сервера.

Замена `config/oc2r/onyxfs.img` задаёт основу для новых корневых дисков, но не переносит файлы из существующих. Старые сохранения имеют отдельные правила совместимости. Перед заменой образов прочитайте [полную документацию](/ru/systems/onyxos-reference).
