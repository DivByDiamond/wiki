# Робототехника

Робот выполняет программу в собственной виртуальной машине. Он перемещается по блокам, а установленные модули позволяют добывать, строить, переносить предметы и исследовать окружение.

Начните с [сборки и первой программы](/ru/robotics/first-robot). Если робот уже работает, откройте [справочник API](/ru/item/robot).

## Движение и координаты

Команды задаются относительно лица робота: вперёд, назад, вверх и вниз. Один успешный вызов перемещает его на один блок. Поворот влево или вправо меняет направление на 90°. Бокового шага нет.

`position()` возвращает положение относительно места установки или последней калибровки. Это локальные координаты. `facing()` сообщает направление по компасу. Поворот робота не поворачивает оси координат.

Готового `goTo(x, y, z)` нет. Программе нужно самой сравнивать позицию с целью, выбирать направление и проверять каждый шаг. Поиск пути и обход препятствий тоже пишутся в программе. Подробности и пример привязки к мировым XYZ есть в разделе [координаты и навигация](/ru/robotics/navigation).

## Что поставить в слоты модулей

| Задача | Модуль | Имя устройства в API |
|---|---|---|
| Разрушать и ставить блоки | [Операции с блоками](/ru/item/block_operations_module) | `block_operations` |
| Брать, выгружать и перекладывать предметы | [Операции с инвентарём](/ru/item/inventory_operations_module) | `inventory_operations` |
| Крафтить по сетке 3×3 | [Крафт](/ru/item/crafting_module) | `crafting` |
| Проверять блоки и сканировать окружение | [Сканер](/ru/item/scanner_module) | `scanner` |
| Передавать данные через связанное туннельное устройство | [Сетевой туннель](/ru/item/network_tunnel_module) | Сетевой интерфейс гостевой ОС |

У робота четыре слота модулей. Подберите комплект под задачу. Рецепты оборудования собраны на странице [крафтов](/ru/recipes).

## Как давать команды

В Linux проще начать с Lua:

```lua
local r = require("robot")
print(r.move("forward"))
print(r.turn("left"))
```

Функции `r.move()` и `r.turn()` ждут завершения и возвращают результат. Прямой вызов `devices:find("robot"):move("forward")` только ставит команду в очередь. Значение `true` ещё не означает, что робот доехал.

В комплекте есть обёртки MicroPython и RPC-библиотеки C/C++. Другие языки тоже могут вызывать API через `/dev/hvc0`, если в гостевой ОС есть нужная программа. Примеры запуска приведены в [руководстве по первому роботу](/ru/robotics/first-robot). Для OnyxOS используйте [команды oc2ctl](/ru/reference/onyx-rpc).
