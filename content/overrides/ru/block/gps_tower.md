# GPS-башня

В обычном режиме GPS-башня сообщает мировые координаты своего основания. Она появилась в исходниках позже первоначального снимка этой wiki, поэтому проверьте наличие блока в своей сборке.

## Установка и подключение

[Скрафтите башню](/ru/recipes#recipe-gps_tower). Для установки нужны прочное основание и свободная вертикальная колонна высотой пять блоков. Подключите основание к компьютеру через интерфейсную шину.

Название устройства в API: `gps_tower`.

```lua
local gps = assert(require("devices"):find("gps_tower"), "Башня не найдена")

if gps:isAssembled() then
    local p = gps:getPosition()
    print("XYZ основания:", p[1], p[2], p[3])
    print("Измерение:", gps:getDimension())
end
```

## Методы

| Метод | Результат |
|---|---|
| `isAssembled()` | `true`, если башня целая и стоит на подходящем основании |
| `getPosition()` | Массив из трёх чисел: мировые X, Y, Z основания |
| `getDimension()` | Идентификатор измерения, например `minecraft:overworld` |

У повреждённой башни `getPosition()` и `getDimension()` вызывают ошибку `GPS tower is incomplete`.

## Относительные координаты и радиосеть

В рабочей версии добавлен переключатель `relative_coordinates`. Он позволяет получать смещение от главной башни своей сети, с дальностью 45 блоков между соседними узлами по умолчанию. Эта возможность может отсутствовать в релизе. [Настройка сети и полный пример](/ru/reference/gps-networks).

## Ограничения

Башня возвращает собственные координаты. Позицию игрока или робота она не определяет. Базовая версия по исходнику внизу страницы не содержит радиосети. Новый режим радиосети описан отдельно; он также не определяет позицию игрока или приёмника.

Робот не подключается к внешней интерфейсной шине. Если программе робота нужны данные башни, передачу от подключённого к ней компьютера нужно организовать отдельно. Для расчёта мирового положения робота также потребуется известное смещение. Пример такой привязки есть на странице [навигации](/ru/robotics/navigation).
