# OC2R: компьютеры в Minecraft

Соберите компьютер, загрузите операционную систему и управляйте миром из программы. OC2R эмулирует RISC-V: у компьютера есть процессор, память, прошивка, диски и подключаемые устройства.

## Начните с первого компьютера

[Руководство по первому запуску](/ru/getting_started) проведёт от установки компонентов до входа в Linux. Для начала достаточно процессора, четырёх модулей памяти по 8 МиБ, прошивки Linux и питания. Отдельный жёсткий диск для загрузки не нужен.

- [Основы работы](/ru/basics) — терминал, компоненты и подключение устройств.
- [Блоки](/ru/block/index) и [предметы](/ru/item/index) — назначение оборудования.
- [Операционные системы](/ru/systems/overview) — Linux и OnyxOS.

## Как пользоваться справочником

Откройте раздел слева или найдите устройство через поиск в шапке. Справа находится оглавление длинной статьи. Язык можно переключить, сохранив текущую страницу; если перевода нет, откроется английская версия.

Статьи основаны на руководстве и документации OC2R. Внизу каждой страницы есть ссылка на источник с зафиксированной ревизией. Параметры сервера и версия сборки могут влиять на характеристики оборудования; [матрица версий](/ru/project/versions) описывает состояние исходного проекта.
