# OC2R: computers in Minecraft

Build a computer, boot an operating system, and write programs that interact with your world. OC2R emulates RISC-V hardware with processors, memory, firmware, storage, and connected devices.

## Build your first computer

Follow the [quickstart guide](/en/getting_started) from installing components to logging into Linux. Start with a CPU, four 8 MiB memory modules, Linux firmware, and power. A separate hard drive is not required to boot.

- [Basics](/en/basics): terminals, components, and device connections.
- [Blocks](/en/block/index) and [items](/en/item/index): the hardware catalogue.
- [Operating systems](/en/systems/overview): Linux and OnyxOS.

## Using this wiki

Browse the sections, search for a device, or use the table of contents on a long page. Switching language keeps the current article. Pages without a translation fall back to English.

Each article links to the OC2R source revision it was imported from. Server settings and build versions can change hardware characteristics. See the [version matrix](/en/project/versions) for the source project's supported targets.
