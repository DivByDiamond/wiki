# Проверка локальной вики


Результат прогона 2026-10-23: 235 Rust-тестов, 8 тестов фронтенда и 3 теста
конвертера прошли; TypeScript, clippy с запретом предупреждений, форматирование,
релизная сборка и лимиты структуры кода прошли. Повторная генерация пакета дала
тот же JSON и изображения. Релизная команда `--sync-content` проверена на новой
временной базе дважды: 134 страницы и 134 ревизии после обоих запусков.

В браузере проверены мобильный экран 390×844, настольная версия, обе темы,
сохранение настроек и фокуса, поиск и его закрытие при отложенном запросе,
подсветка результатов, якоря и английский fallback. Статья также открыта
в sandbox-iframe с запрещёнными скриптами: текст и оглавление доступны.
Административное создание страниц и изменение навигации проверены интеграционно;
настоящий GitHub-вход в браузере не проверялся.

Проверка выполняется на локальном checkout. Для воспроизводимого прогона:

```bash
python3 -m unittest discover -s scripts/content -v
(cd web && bun run build && bun run check && bun test)
cargo fmt --all --check
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
cargo build --release -p oc2r-wiki
```

Проверка наполнения входит в Rust-тесты: открываются все статьи и все внутренние
ссылки пакета, включая изображения и английский fallback. Проверяются якоря
оглавления, повторный импорт без дублей ревизий, защита ручных правок и удалённых
страниц, обновления импорта и атомарный откат некорректного пакета.

Браузерная приёмка:

- Главная и статья с оглавлением в светлой и тёмной теме.
- Экран 390×844, отсутствие горизонтального переполнения и свёрнутое меню.
- Настройки применяются сразу, сохраняются после перезагрузки, язык панели
  соответствует языку страницы.
- `/` переводит фокус в поиск; поиск выводит результаты, `Escape` закрывает их,
  в том числе при ещё не завершённой задержке или запросе.
- Переход к якорю оглавления находит нужный заголовок.
- Переключение языка сохраняет статью; без перевода показывается английский текст.
- Чтение статьи и оглавление работают без JavaScript.

Интеграционные тесты используют временную SQLite-базу и тестового провайдера GitHub.
Они проверяют вход, права, API, предложения, модерацию, историю и откат. Настоящий
GitHub callback требует настроенных OAuth-данных. Проверка nginx, Cloudflare,
публикации и резервного копирования на production не входит в локальный прогон.

Ограничения исходного плана: загрузка изображений через админку и отдельная страница
«Мои предложения» отложены в `todo.md`. Изображения руководства уже входят в сборку
и доступны по обычным URL; административный загрузчик для этого не требуется.
