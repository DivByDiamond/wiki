# Читатель, стиль, ошибки, тесты

## Информационная архитектура

```
Начало               Быстрый старт, Основы
Блоки и предметы     Computer, Monitor, Projector, Keyboard, Disk Drive,
                     Flash Memory Flasher, Redstone Interface, кабели и шина
Сети                 Network Hub / Connector, Internet Gateway
Роботы
Системы              OnyxOS, свой образ Linux (Buildroot)
Скрипты и API        Lua: первые шаги, справочник устройств, примеры
Журнал изменений
```

Порядок разделов фиксированный: «Системы» стоят перед «Скриптами и API».
Дерево разделов хранится как поля страницы (`section`, `position`), отдельной таблицы нет.

## Страницы

- **Статья:** слева дерево разделов, по центру текст, справа оглавление статьи.
  Внизу «История», «Предложить правку», «Назад» и «Дальше».
- **Шапка:** логотип, поиск (быстрая клавиша `/`), переключатель языка, значок настроек.
- **Поиск:** FTS5, подсветка совпадений, результаты по текущему языку, затем по en.
- **Язык:** нет перевода → показывается en с плашкой «Перевода пока нет. Предложить?».
- **Старая версия:** плашка сверху (см. `workflows.md`).
- Страницы отдаются как готовый HTML. JS улучшает, но не требуется для чтения.

## Стиль

Основа: чистая техдокументация. Из Minecraft берём заметные детали.

- Светлая и тёмная темы, один акцентный цвет (по умолчанию зелёный). Контраст не ниже AA.
- Шапка и боковая колонка отделены толстой чёрной линией. Заголовки моноширинные.
- Плашки подсказок и предупреждений: толстая рамка, жёсткая тень без размытия.
- Крафт-сетка 3×3 в стиле слотов игры, активный пункт меню залит акцентом.
- Всё «игровое» подчиняется CSS-переменной `--pixel` (0 или 1). Выключение даёт обычные тонкие рамки.
- Уважается `prefers-reduced-motion`. Анимаций почти нет.

## Настройки читателя

Панель по значку ⚙. Хранится в `localStorage`, аккаунт не нужен.

| Настройка | Значения |
|---|---|
| Тема | светлая, тёмная, авто |
| Акцент | набор из 4–5 цветов |
| Размер шрифта | A−, A, A+ |
| Пиксель-рамки | вкл, выкл |

Маленький скрипт в `<head>` ставит тему до отрисовки, чтобы не было вспышки.
Если `localStorage` недоступен, сайт работает с настройками по умолчанию.

## Расширения Markdown

Минимальный набор, все разбираются в `render/extensions.rs`:
- `:::tip`, `:::warn` — плашки.
- `:::recipe` — крафт-сетка, 9 строк слотов.
- `:::version 26.x` — плашка «только для версии».
HTML внутри Markdown вырезается (`render/sanitize.rs`), чтобы нельзя было вставить скрипт.

## Ошибки

- 404 показывает поиск и похожие slug. Если страница была удалена, админ видит пометку.
- Любая ошибка API и админки идёт через один тип `AppError` (DRY), он же задаёт код и JSON.
- Сбой GitHub OAuth возвращает на страницу с понятным сообщением, вход можно повторить.
- Лимиты запросов: 429 с `Retry-After`.

## Тесты

- **Юнит:** рендер и расширения, создание ревизий, откат, diff, `policy.can`, хеширование ключей.
- **Интеграционные:** API и админка на временной SQLite-базе: ключи, права, запись, предложения, конфликт.
- **Сквозной:** предложение → принятие → видно в истории → откат → старая ревизия открывается.
- Хранилище в юнит-тестах заменяется реализацией портов в памяти.
