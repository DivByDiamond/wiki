# Roadmap: QoL и дизайн (2026-11-03)

Статус: в работе. Реализация идёт параллельными потоками, у каждого свои файлы.
Единственная ветка репозитория: `main`.

## Потоки

| Поток | Область | Пункты |
|---|---|---|
| A. Reader | `web/src/reader`, `web/src/search`, шаблоны reader | QoL 1, 2, 7, 8, 9 |
| B. Backend | `server/src/http`, `server/src/store`, миграции, тесты | QoL 3, 4, 5 |
| C. Editor | `web/src/editor`, `server/templates/admin` | QoL 6, дизайн 6 |

## QoL

1. [ ] Поиск по `Ctrl+K` / `/`: палитра команд, живые подсказки, последние запросы, переход по страницам и заголовкам.
2. [ ] Кнопка «Копировать» в блоках кода, подсветка Lua, якорные ссылки на заголовки.
3. [ ] Страница «Недавние изменения» и RSS/Atom (данные из ревизий).
4. [ ] «Мои предложения»: статусы правок читателя (на рассмотрении, принято, отклонено).
5. [ ] Загрузка картинок в админке (таблица `media` уже есть, нужны маршруты и UI).
6. [ ] Редактор: автосохранение черновика в `localStorage`, предупреждение о несохранённых правках, `Ctrl+S`, `Ctrl+B`.
7. [ ] Читатель: запоминание прокрутки, «Наверх», панель «На этой странице» с подсветкой раздела, время чтения.
8. [ ] Печать-стиль и экспорт страницы (PDF через печать, Markdown).
9. [ ] Поиск: фильтр по разделу и языку (подсветка совпадений уже есть).

## Дизайн

1. [ ] Типографика: пиксельный шрифт только для заголовков, текст 16–18px, интерлиньяж 1.6–1.7.
2. [ ] Тема Minecraft: низкоконтрастный фон-булыжник/дерево, панели-слоты, кнопки с фасками, пиксельные рамки как единый язык.
3. [ ] Контраст по WCAG AA в обеих темах, один акцентный цвет.
4. [ ] Сайдбар: сворачиваемые разделы с иконками, выделенная текущая страница, выезжающая панель на мобильных.
5. [ ] Мобильная версия: липкая шапка с поиском, зоны нажатия ≥44px, горизонтальная прокрутка таблиц.
6. [ ] Редактор: split-view с синхронной прокруткой, подсказки у кнопок тулбара.
7. [ ] Скелетоны, переходы 150–200ms, уважение `prefers-reduced-motion`.
8. [ ] Callout-блоки (note, warning, tip) в стиле подсказок Minecraft, заметные ссылки на соседние страницы.

## Правила

- Без рантайм-библиотек во фронтенде (как в основном плане).
- Каждый пункт: тест или проверка, `cargo test`, `cargo clippy -- -D warnings`, `bun test`, `bun run build` проходят.
- Отмечать пункты `[x]` только после проверки.
