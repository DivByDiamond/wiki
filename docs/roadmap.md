# Roadmap: QoL и дизайн (2026-11-03)

Статус: в работе. Реализация идёт параллельными потоками, у каждого свои файлы.
Единственная ветка репозитория: `main`.

## Потоки

| Поток | Область | Пункты |
|---|---|---|
| A. Reader | `web/src/reader`, `web/src/search`, шаблоны reader | QoL 1, 2, 7, 8, 9 |

## QoL

1. [x] Поиск по `Ctrl+K` / `/`: палитра команд, живые подсказки, последние запросы, переход по страницам и заголовкам.
2. [ ] Кнопка «Копировать» в блоках кода, подсветка Lua, якорные ссылки на заголовки.
3. [x] Страница «Недавние изменения» и RSS/Atom (данные из ревизий).
4. [x] «Мои предложения»: статусы правок читателя (на рассмотрении, принято, отклонено).
5. [x] Загрузка картинок в админке (таблица `media` уже есть, нужны маршруты и UI).
6. [ ] Редактор: автосохранение черновика в `localStorage`, предупреждение о несохранённых правках, `Ctrl+S`, `Ctrl+B`.
7. [x] Читатель: запоминание прокрутки, «Наверх», панель «На этой странице» с подсветкой раздела, время чтения.
8. [ ] Печать-стиль и экспорт страницы (PDF через печать, Markdown).
9. [x] Поиск: фильтр по разделу и языку (подсветка совпадений уже есть).
10. [x] Лайтбокс для картинок: клик или тап приближает, щипок и перетаскивание на телефоне, колесо на ПК, стрелки между фото.

## Дизайн

1. [x] Типографика: пиксельный шрифт только для заголовков, текст 16–18px, интерлиньяж 1.6–1.7.
2. [x] Тема Minecraft: низкоконтрастный фон-булыжник/дерево, панели-слоты, кнопки с фасками, пиксельные рамки как единый язык.
3. [x] Контраст по WCAG AA в обеих темах, один акцентный цвет.
4. [x] Сайдбар: сворачиваемые разделы с иконками, выделенная текущая страница, выезжающая панель на мобильных.
5. [x] Мобильная версия: липкая шапка с поиском, зоны нажатия ≥44px, горизонтальная прокрутка таблиц.
6. [ ] Редактор: split-view с синхронной прокруткой, подсказки у кнопок тулбара.
7. [x] Скелетоны, переходы 150–200ms, уважение `prefers-reduced-motion`.
8. [x] Callout-блоки (note, warning, tip) в стиле подсказок Minecraft, заметные ссылки на соседние страницы.

## Правила

- Без рантайм-библиотек во фронтенде (как в основном плане).
- Каждый пункт: тест или проверка, `cargo test`, `cargo clippy -- -D warnings`, `bun test`, `bun run build` проходят.
- Отмечать пункты `[x]` только после проверки.

## Не проверено в браузере

- QoL 2: кнопка копирования (нужен настоящий клик), якоря и подсветка Lua проверены.
- QoL 6 и дизайн 6: редактор (черновик, горячие клавиши, split-view, сохранение через fetch).
- QoL 8: печать и экспорт `?md`.
- Анимации (drawer, скелетоны), `prefers-reduced-motion`, перевод zh, жесты лайтбокса на реальном телефоне.
