# Удобство вики и администрирования

Аудит интерфейса 2026-10-23 проведён по исходникам, затем изменения проверены
в браузере. Приоритет — поиск нужной статьи, понятное редактирование и сохранение
языка на всём пути пользователя.

## Реализованные изменения

- Поиск по названию и адресу страниц, фильтры языка и раздела, счётчик результатов,
  сброс фильтров и состояние без результатов. Фильтры работают без JavaScript
  и сохраняются в URL.
- Таблица страниц с читаемыми названиями разделов, отдельными ссылками редактирования
  и просмотра. В узком окне прокручивается таблица, а не вся страница.
- Постоянная навигация: страницы, предложения, пользователи и API-ключи.
- Удаление убрано из основных действий в раскрываемый блок с подтверждением;
  удалённые страницы доступны для восстановления в отдельном списке.
- Редактор с понятным названием действия «Сохранить и открыть», подписью
  предпросмотра и отдельной историей. На широком экране текст и предпросмотр рядом,
  на узком — друг под другом.
- Интерфейс en/ru, выбор по языку браузера и сохранение явного выбора.
  Язык интерфейса независим от языка редактируемой статьи.
- Компактная шапка с обычными навигационными раскрывающимися списками, клавиатурным
  управлением и доступными названиями иконок. Добавлены favicon и иконка для iOS.
- Адреса CSS/JavaScript содержат версию содержимого сборки, чтобы новая разметка
  загружала соответствующие стили после публикации.

Это адаптация рекомендаций к рабочим процессам OC2R Wiki, а не результат
формального пользовательского исследования:

- [GOV.UK: таблицы](https://design-system.service.gov.uk/components/table/) —
  семантические заголовки и сопоставимые строки данных.
- [GOV.UK: навигация сервиса](https://design-system.service.gov.uk/components/service-navigation/) —
  постоянные разделы и явное текущее положение.
- [GOV.UK: кнопки](https://design-system.service.gov.uk/components/button/) —
  названия по выполняемому действию и различимый основной шаг.

  названия языков на соответствующем языке и последовательное расположение.

## Дизайн-система (Minecraft)

- Шрифт: Monocraft Bold, подмножество latin+cyrillic (SIL OFL 1.1, `web/public/fonts/OFL.txt`), самохостинг woff2
  (латиница и кириллица, около 14 КБ) только для заголовков и логотипа. Текст — системный
  sans, 17px (15/17/19 в настройках), интерлиньяж 1.65, в статьях 1.7.
- Фон — «булыжник» из маленького SVG-тайла в CSS-переменной `--stone-tex`, низкий контраст;
  контент лежит на панелях со скосами (`--bevel-hi`/`--bevel-lo`). Кнопки, пагинация и
  переключатели используют тот же скос. При `data-pixel="0"` всё становится плоским.
- Callout-блоки `:::note`, `:::tip`, `:::warn`, `:::version` выглядят как подсказки
  предметов; тип передан подписью (en/ru) и значком, а не только цветом.
- Сайдбар: сворачиваемые разделы с иконками, состояние запоминается, текущая страница
  выделена; до 720px выезжающая панель (`Esc`, фон, Tab остаётся внутри). Без JS сайдбар
  просто идёт перед статьёй.
- Мобильная шапка липкая (логотип и меню, ниже кнопка меню и поиск), цели нажатия не
  меньше 44px, таблицы и код прокручиваются внутри блока.
- Переходы 180ms (`--t`); при `prefers-reduced-motion` анимации отключены.
  Скелетоны: `.skeleton-line` или `aria-busy="true"` на пустом `#search-results`.

### Контраст WCAG AA

Проверка: `cd web && bun run dev/contrast.ts` (читает `styles/tokens.css`, завершается
с ошибкой при нарушении). Текст и ссылки — минимум 4.5:1, фокус и границы — 3:1.

| Пара | Светлая | Тёмная |
|---|---|---|
| Основной текст на панели | 15.95 | 12.36 |
| Приглушённый текст на панели / на bg-alt | 7.12 / 6.33 | 6.63 / 5.80 |
| Ссылки (акцент green) на панели | 6.33 | 8.49 |
| Худший из четырёх акцентов на bg-alt (teal / violet) | 5.07 | 6.42 |
| Текст основной кнопки (green) | 6.61 | 10.78 |
| Предупреждение / заметка на панели | 7.20 / 6.79 | 7.78 / 7.20 |
| Заголовок и текст подсказки callout | не ниже 9.19 | то же |

Все 46 проверенных пар проходят. Акцент по умолчанию один (зелёный) для ссылок и кнопок;
альтернативные акценты из настроек тоже проверены.
